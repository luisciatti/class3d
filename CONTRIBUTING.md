# Contribuindo

1. Pegue uma Issue (tarefa `T-xxx` do `docs/BACKLOG.md`).
2. Crie uma branch: `feat/T-014-nome-curto`.
3. Commits no padrão **Conventional Commits** (`feat:`, `fix:`, `chore:`, `docs:`, `ci:`).
4. Antes do PR: `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
5. Abra o PR com `Closes #N` e preencha o checklist. O check `ci` precisa estar verde.

Mais contexto sobre o projeto e as regras para a IA: `AGENTS.md`.
